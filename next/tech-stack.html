The 5 Senior Architecture Pillars

Strict engineering principles governing every file, component, hook, and API interaction in the Next.js enterprise migration.

01

Centralized Query Key Factory

Single source of truth in query-keys.ts. Every TanStack hook uses typed key factories (adminKeys.users()) to guarantee 100% bug-free cache invalidations across mutations.

02

RAM In-Memory Session

JWT access tokens are stored strictly in RAM memory via Zustand. Zero disk trace in localStorage renders the platform immune to XSS token theft. F5 refreshes are silently healed via secure HttpOnly cookies.

03

Optimistic UI Mutations

Actions like role changes, DRM unlocks, or status toggles update the UI immediately without waiting for server round-trips. If an error occurs, the cache automatically rolls back with a toast alert.

04

Zero Bespoke Custom CSS

Zero messy CSS files or random color classes. All styling strictly utilizes pre-built Shadcn UI primitives, Lucide React icons, and high-gamut Tailwind CSS OKLCH design tokens.

05

Defense-In-Depth Security

Multi-tier protection combining Next.js clickjacking defense (X-Frame-Options: DENY), MIME sniffing locks, and real-time LMS lecture DRM stream screen-grab freeze detection.
