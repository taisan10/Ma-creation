HIGHUnauthenticated / Unchecked AES-128 Key Delivery Endpoint Lacks Playback Token ValidationSECURITY_VULNERABILITYOPEN

backend/src/controllers/videoController.js:27 · VERIFIED confidence: HIGH

Evidence

router.get('/:videoId/key', requireVideoEntitlement, asyncHandler(c.getVideoKey)) calls VideoService.getVideoKey({ video, userId, req }), which verifies User.playbackLocked and WatchLog watch limit, but completely ignores req.query.token and does not verify the existence of an active, valid PlaybackSession.

Impact

Any entitled user possessing a standard Bearer JWT can retrieve the raw 16-byte AES-128 DRM key directly without starting a playback session, allowing offline caching and decryption.

Reproduction

curl -H 'Authorization: Bearer <STUDENT_JWT>' http://localhost:5000/api/videos/<VIDEO_ID>/key -> Returns 200 OK with raw 16-byte binary decryption key without initiating PlaybackSession.

Suggested remediation

Validate req.query.token against PlaybackSession in VideoService.getVideoKey, verify session.expiresAt > new Date(), session.video == videoId, and session.user == userId before returning key buffer.

Regression test

Call GET /api/videos/:videoId/key without a valid, unexpired playback session token and assert response is 401/403.

HIGHHLS Segment Streaming Endpoint Omits Watch Limit and Quota VerificationSECURITY_VULNERABILITYOPEN

backend/src/controllers/videoController.js:83 · VERIFIED confidence: HIGH

Evidence

router.get('/:videoId/hls/:segment', requireVideoEntitlement, asyncHandler(c.getHlsSegment)) only executes requireVideoEntitlement, which checks plan ownership. Neither getHlsSegment nor requireVideoEntitlement checks WatchLog.totalWatchedSeconds >= maxAllowedSeconds.

Impact

Users whose watch limit has expired can continue streaming all video chunks (.ts) directly from MinIO as long as they retain the encryption key, bypassing all plan watch caps.

Reproduction

Consume full watch quota for a video. Issue GET /api/videos/:videoId/hls/res_1080p_seg_000.ts. Server returns 200 OK with video/MP2T content.

Suggested remediation

Add watch quota verification middleware to getHlsSegment or validate active non-expired PlaybackSession on segment streaming requests.

Regression test

Request HLS segment after WatchLog.totalWatchedSeconds exceeds maxAllowedSeconds and verify 403 WATCH_LIMIT_REACHED is returned.
